# Mongo MCP Lab

A Java and Spring AI application exploring the official MongoDB MCP server
through complex sales queries and multi-collection aggregations.

## Planned stack
- Java and Spring Boot
- Spring AI and an OpenAI model
- Official MongoDB MCP server
- MongoDB

## Scope
Six collections: customers, orders, products, payments, returns, and inventory.
Read-only database exploration with visible tool calls and supporting results.
